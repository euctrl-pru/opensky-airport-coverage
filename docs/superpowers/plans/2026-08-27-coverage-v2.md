# Airport Coverage v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the endpoint-based capture metric with a measured-continuity one, add a per-aerodrome H3 surface-coverage map, make the site readable without a glossary, and add the 2026 period.

**Architecture:** Unchanged in shape — a Spark job on the OSN cluster writes small tables, everything after renders offline. Two new cluster outputs: per-flight ground-phase occupancy, and per-aerodrome H3 cell counts.

**Tech Stack:** Python 3.10, PySpark 4.1.1 (cluster only), pandas 2.3, matplotlib, h3 3.7.7, Quarto 1.10.

**Spec:** `docs/superpowers/specs/2026-08-27-airport-coverage-design.md`, amended by this plan's "What changes from v1" section.

## Global Constraints

Everything in the v1 plan's Global Constraints still holds. Additions:

- **`h3` is pinned below 4.0 and the v3 API is used** (`geo_to_h3`, `h3_to_parent`, `h3_to_geo_boundary`). Not a preference: `h3-pyspark`, which the cluster path needs through `opdi.pipeline.tracks`, requires v3. opdi's own venv has 4.5.0 with an incompatible API, so a v4 call here works in one environment and fails in the other.
- **Continuity bins are 30 s.** At the 5 s decimation cadence a bin should hold ~6 samples, so an empty bin is a reception gap rather than jitter or one dropped message.
- **H3 resolution 11** — 28.7 m edge, 2,150 m². A runway is 45–60 m wide, so ~2 cells across it. Res 12 (10.8 m) triples the row count for detail below the position accuracy of the data.
- **Reach is retained, never deleted.** The v1 metric becomes `dep_reach` / `arr_reach` and stays on every page as a diagnostic. Reach high with continuity low is the exact signature of "one sample at the stand and nothing else", which is the defect this plan exists to fix — deleting reach would hide it.

---

## What changes from v1, and why

**The defect.** `dep_capture = clip((ATOT − trk_start) / (ATOT − AOBT), 0, 1)` measures how far back in the taxi the *earliest* sample lies. It says nothing about what happened in between. A single state vector at push-back and nothing again until wheels-off scores **1.000** — indistinguishable from a receiver that watched every second of the taxi.

**The fix.** Divide each ground phase into 30 s bins and count how many contain at least one state vector:

```
dep_continuity = bins_containing_a_sample / total_bins   over [AOBT, ATOT]
arr_continuity = bins_containing_a_sample / total_bins   over [ALDT, AIBT]
```

**Consequence, stated plainly: every published number changes.** The Coverage Index becomes `detection_rate × mean(dep_continuity_p50, arr_continuity_p50)`, so the ranking is not comparable with the v1 tables. That is the point, and the site must say so rather than quietly renumbering.

Ground samples are therefore not in `matched` at all, and this cannot be computed from it. A second range join on `[aobt, t_off]` and `[t_land, aibt]` is required, against the same unfiltered assignment table `track_extents` uses.

Bins are half-open and anchored at the window start, so bin `k` covers `[start + k·30, start + (k+1)·30)`. `bins_total = ceil(duration / 30)`, computed from the window rather than from the data — a window with no samples must yield `bins_seen = 0`, not a division by zero.

```python
"""Was the aerodrome surface actually observed, or merely spanned?

`oac.offsets` measures **reach**: how far before wheels-off the earliest
sample lies. It says nothing about what happened in between, so a single state
vector at push-back and nothing until the runway scores a perfect 1.000 --
identical to a receiver that watched every second of the taxi.

This module measures **continuity**: the ground phase is divided into 30 s
bins and each is asked whether any state vector fell inside it. At the feed's
5 s decimation a bin should hold about six samples, so an empty bin is a
reception gap rather than jitter or one dropped message.

**This cannot be computed from `matched`.** `track_truth.overlap_join` joins on
the *airborne* interval `[t_off, t_land]`, so ground samples are not in it at
all. The join here is against the unfiltered assignment table, on
`[aobt, t_off]` and `[t_land, aibt]`.
"""

from pyspark.sql import DataFrame, Window
from pyspark.sql import functions as F

#: Bin width in seconds. See the module docstring for why 30 and not 5.
BIN_S = 30

__all__ = ["BIN_S", "ground_occupancy"]


def _side(assign: DataFrame, gt: DataFrame, side: str, bin_s: int) -> DataFrame:
    """Occupancy of one ground phase, one row per flight that has one."""
    start, end = (("aobt", "t_off") if side == "dep" else ("t_land", "aibt"))
    measured = f"{side}_measured"

    w = (
        gt.filter(F.col(measured))
        .select("flight_key", "icao24",
                F.col(start).alias("w_start"), F.col(end).alias("w_end"))
        # A non-positive window is bad reference data, not zero coverage. It is
        # dropped here and counted by `oac.aggregate` as n_capture_excluded --
        # keeping it would make bins_total zero and every ratio undefined.
        .filter(F.col("w_end") > F.col("w_start"))
    )

    j = assign.alias("a").join(
        w.alias("w"),
        (F.col("a.icao24") == F.col("w.icao24"))
        & (F.col("a.event_time") >= F.col("w.w_start"))
        & (F.col("a.event_time") < F.col("w.w_end")),
        "inner",
    ).select(
        F.col("w.flight_key").alias("flight_key"),
        F.col("w.w_start").alias("w_start"),
        F.col("w.w_end").alias("w_end"),
        F.col("a.event_time").alias("event_time"),
    )

    # Half-open bins anchored at the window start: bin k is
    # [w_start + k*bin_s, w_start + (k+1)*bin_s).
    binned = j.withColumn(
        "_bin",
        F.floor(
            (F.unix_timestamp("event_time") - F.unix_timestamp("w_start")) / bin_s
        ),
    )

    # Longest silence inside the window, including the lead-in from the window
    # start and the run-out to its end -- a receiver that stops halfway has a
    # gap even though no two samples straddle it.
    ordered = Window.partitionBy("flight_key").orderBy("event_time")
    gaps = binned.withColumn(
        "_prev",
        F.coalesce(F.lag("event_time").over(ordered), F.col("w_start")),
    ).withColumn(
        "_gap", F.unix_timestamp("event_time") - F.unix_timestamp("_prev")
    )

    agg = gaps.groupBy("flight_key").agg(
        F.countDistinct("_bin").alias(f"{side}_bins_seen"),
        F.count(F.lit(1)).alias(f"{side}_n_samples"),
        F.max("_gap").alias("_max_inner_gap"),
        F.max("event_time").alias("_last"),
        F.first("w_end").alias("_w_end"),
    )
    agg = agg.withColumn(
        f"{side}_max_gap_s",
        F.greatest(
            F.col("_max_inner_gap"),
            F.unix_timestamp("_w_end") - F.unix_timestamp("_last"),
        ).cast("double"),
    ).drop("_max_inner_gap", "_last", "_w_end")

    # Left join from the windows, not from the samples: a flight never seen on
    # the ground must appear with zero, which is the finding, rather than
    # vanish, which looks like the flight not existing.
    total = w.select(
        "flight_key",
        F.ceil(
            (F.unix_timestamp("w_end") - F.unix_timestamp("w_start")) / bin_s
        ).cast("long").alias(f"{side}_bins_total"),
    )
    out = total.join(agg, "flight_key", "left")
    return (
        out.withColumn(f"{side}_bins_seen",
                       F.coalesce(F.col(f"{side}_bins_seen"), F.lit(0)))
        .withColumn(f"{side}_n_samples",
                    F.coalesce(F.col(f"{side}_n_samples"), F.lit(0)))
        .withColumn(
            f"{side}_max_gap_s",
            # No samples at all: the gap is the whole window.
            F.coalesce(
                F.col(f"{side}_max_gap_s"),
                (F.col(f"{side}_bins_total") * bin_s).cast("double"),
            ),
        )
    )


def ground_occupancy(assign: DataFrame, gt: DataFrame,
                     bin_s: int = BIN_S) -> DataFrame:
    """One row per ground-truth flight with a measured ground phase.

    Flights with neither side measured do not appear; the caller left-joins
    this onto the full flight table, so their columns become NULL -- which is
    "not measurable here", a different statement from zero coverage.
    """
    dep = _side(assign, gt, "dep", bin_s)
    arr = _side(assign, gt, "arr", bin_s)
    return dep.join(arr, "flight_key", "outer")
```
